# Retro Explorer

The retro browser that can run modern websites.

**Download page:** https://lompendans.github.io/retro-explorer/
**Latest download:** [Releases](https://github.com/lompendans/retro-explorer/releases/latest)

Runs on Windows 7 SP1, 8.1, 10 and 11. Retro Explorer is an independent project and is not affiliated with Microsoft.
